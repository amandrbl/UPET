# UPET 🐾

## 🐶🐱 Sobre o aplicativo 
- Neste repositório, você irá conhecer um pouco mais sobre o aplicativo UPET – aplicativo vencedor da Feira de Tecnologia FMM 2023.
- O UPET é um projeto, que tem como objetivo combater os maus-tratos e abandono de animais domésticos que se encontram em situação de vulnerabilidade na cidade de Manaus.
- Projeto Final, desenvolvido para formação como TI na Fundação Matias Machline
- Desenvolvido em equipe 

## 🛠️ Ferramentas
- Dart
- Flutter
- Intellij Idea
- Diagramas UML
- Figma
